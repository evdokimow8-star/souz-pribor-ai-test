# Дифференциальный манометр testo 510

Дифференциальный манометр testo 510 предназначен для измерения перепада давления в диапазоне от 0 до 100 гПа. Прибор используется для контроля состояния фильтров и работы вентиляционных систем. Устройство поддерживает отображение данных в различных единицах измерения, включая Па. Разрешение прибора составляет 0,01 гПа, что обеспечивает детальную фиксацию показаний.

Конструкция testo 510 включает магнитное крепление на задней панели корпуса для фиксации на металлических поверхностях и подсветку дисплея для работы в условиях недостаточного освещения. В приборе реализована функция температурной компенсации. Корпус имеет класс защиты IP40. Питание осуществляется от двух батареек типа ААА, входящих в систему энергоснабжения.

Эксплуатация манометра testo 510 возможна при температуре окружающей среды от 0 до +50 °C. Прибор позволяет проводить измерения скорости воздушного потока при совместном использовании с трубкой Пито. Обратите внимание, что данная трубка является опциональным аксессуаром, и информация о её наличии в стандартном комплекте поставки данного устройства отсутствует.

## Характеристики

- Тип прибора: Дифференциальный манометр
- Диапазон измерений: 0 ... 100 гПа
- Погрешность: ±0,03 гПа (0 ... 0,30 гПа); ±0,05 гПа (0,31 ... 1,00 гПа); ±(0,1 гПа + 1,5 % от изм. знач.) (1,01 ... 100 гПа)
- Разрешение: 0,01 гПа
- Защита корпуса: IP40
- Питание: Батарейки ААА, 2 шт.
- Рабочая температура: 0 ... +50 °C
- Гарантия: данных нет
