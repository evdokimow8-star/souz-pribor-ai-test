## Overview

Согласованное направление — компактное рабочее место технического редактора. Сохраняется светлая бело-синяя гамма существующего сервиса. Предметность дают настоящие приборы, точные значения и проверяемые источники.

## Colors

Белый рабочий лист, спокойный серо-синий фон, графитовый текст. Синий обозначает действие и выбранный режим. Янтарный — сведения для уточнения. Статус проверки всегда подписан словами.

## Typography

Локальные файлы Manrope с кириллицей и латиницей. Основной текст 16px, значимый вспомогательный 13–14px, поля 16px. Заголовки 24–32px. Моноширинный шрифт только у JSON.

## Layout

Без большого вступительного блока. На телефоне сразу открыта настоящая карточка; доступны режимы «Карточка», «Данные», «Проверки». Действия с результатом рядом, на узком экране закреплены с безопасными отступами. На большом экране исходные данные и карточка рядом; левая колонка не растягивается пустотой до высоты статьи. Максимальная ширина рабочей области 1360px.

## Elevation & Depth

Тонкая граница разделяет рабочие области. Тень только у всплывающего экспорта, сообщения о результате действия и диалога, без декоративных ореолов.

## Shapes

Скругление панелей 14px, контролов 8px; минимум 44px для нажатия. Иконки — единый набор контурных SVG с одинаковой толщиной.

## Components

Проверяемый товар, источник и замечания предшествуют длинным техническим подробностям. Форма и JSON редактируют один вход. Предыдущая успешная карточка сохраняется с явной отметкой при изменении исходника. Доказательства доступны из соответствующего текстового блока.

## Do's and Don'ts

Сохранять ясный русский текст, видимый фокус, reduced-motion, возможность увеличения и все сведения задания. Не уменьшать текст ради размещения. Не обещать полную достоверность. Не показывать устаревший результат как новый. Не включать платные повторы.
