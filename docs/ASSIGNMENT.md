# Сверка с тестовым заданием «Союз-Прибор»

Проверено по [исходному заданию](https://drive.google.com/file/d/1CcfOkv2K2CG8k7Ys1X430QRH_ZR-IGT6/view). Прототип решает задачу подготовки черновика карточки из фактов о приборе.

1. **Вход и сценарий работы.** Форма и JSON принимают название, производителя, характеристики и описание. Для другого товара есть отдельная кнопка «Ввести свой прибор». Готовые примеры не расходуют бюджет. Кнопка «Создать карточку с ИИ» выполняет один новый запрос.
2. **Модель и результат.** Сервер Python передаёт факты в Gemini 4 Argon через OpenRouter. При замечаниях проверки та же модель может один раз исправить текст. Сохранённые примеры подписаны исходной моделью Gemini 3 Flash Preview. Карточка содержит заголовок до 70 символов, описание от 800 до 1200, таблицу характеристик, 3–5 поисковых фраз и блок для менеджера. Копирование выдаёт обычный текст. Результат можно скачать в JSON или Markdown.
3. **Недостающие и недостоверные данные.** Пустые характеристики помечаются «данных нет», замечания вынесены отдельно. Характеристики берутся из ввода программно. В тексте проверяются ссылки на факты, числа со знаком, сочетания значения с единицей и технические обозначения. Редактор проверяет смысл утверждений перед публикацией.
4. **Два товара из каталога.** У [testo 510](../examples/results/testo-510.md) заголовок 35 символов, описание 1011 и четыре поисковые фразы. У [testo 511](../examples/results/testo-511.md) заголовок 39 символов, описание 817 и четыре поисковые фразы. Оба примера основаны на реальных ответах API и вычитаны редактором. В обоих блоках для менеджера указаны аудитория и задачи. У каждого товара на странице расходятся сроки гарантии, поэтому значение оставлено неизвестным. [Происхождение примеров](../examples/SOURCES.md).
5. **Ошибки и ключ.** Неверный JSON и типы, нехватка данных, ошибки доступа к API, лимиты, сетевой сбой, тайм-аут и отклонённый ответ обрабатываются отдельно. Сбой не стирает предыдущую карточку. Ключ берётся из окружения или исключённого из Git `.env`; в репозитории только пустой образец настройки.
6. **Что приложено.** [README](../README.md) содержит запуск без установки Python-пакетов, настройку API, инструкцию демо и ссылки на оба результата. [Промпт](../pribor/llm.py) находится в коде, [обоснование решений, ограничения и развитие](DECISIONS.md) — отдельно. [Сопроводительное сообщение](../SUBMISSION.md) и снимки экрана готовы.
7. **Границы решения.** Публичное демо дополняет локальный запуск. Исходные данные вводит пользователь: ссылка служит для проверки фактов. Задачи автоматического обхода каталога и публикации в CMS выходят за рамки этого прототипа.
