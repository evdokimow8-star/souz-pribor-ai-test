Подготовил прототип AI-помощника для создания товарных карточек по техническим данным.

В репозитории — локальный сервис на Python, адаптивный редактор, подключение LLM API, два реальных примера из вашего каталога, тесты и инструкция запуска. Демонстрация открывается сразу с готовой карточкой, работает на телефоне и компьютере. Данные можно вводить полями или JSON; результат — редактировать, копировать и скачивать. Черновики сохраняются в браузере. Для локального запуска не нужны дополнительные зависимости, а ключ новой генерации задаётся через окружение.

Основной акцент сделал на проверяемости: характеристики переносятся из исходных данных программно, тексты связаны с фактами, после ответа проверяются структура, объём, числа и технические обозначения. Недостающие сведения выводятся отдельно. У выбранных товаров нашлось противоречие по гарантии — оно явно отмечено, без произвольного выбора значения.

В README описаны принятые решения, обработка ошибок, ограничения и дальнейшие улучшения. Формальные проверки не заменяют технического редактора, поэтому результат обозначен как черновик. Скриншоты интерфейса приложены в репозитории.
